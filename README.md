## Описание

Локальное приложение для ведения дел. Позволяет создавать и редактировать дела, закрывать их, искать по названию и описанию, фильтровать по дедлайну и вести историю комментариев.

Приложение работает без подключения к интернету. Все пользовательские данные хранятся локально в отдельных JSON-файлах.

## Возможности

- создание и редактирование дел;
- закрытие дел с автоматической отметкой времени;
- хранение даты и времени обещания и дедлайна;
- поиск по названию и описанию без учёта регистра;
- просмотр дел за выбранный день, неделю или календарный месяц;
- фильтрация по произвольному диапазону дат;
- комментарии с автоматической отметкой времени;
- автоматическое сохранение черновиков;
- восстановление ввода после переключения между карточками и перезапуска;
- продолжение работы при наличии отдельных повреждённых записей.

## Требования
- Операционная система: Ubuntu 24.04.3 LTS (разработка и тестирование в WSL2).
- Python 3.12;
- Streamlit 1.39 или новее, но ниже версии 2.0.

## Установка и запуск

Перейдите в корень проекта и создайте виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Установите зависимости:

```bash
python -m pip install -r requirements.txt
```

Запустите приложение:

```bash
python -m streamlit run app.py
```

После запуска откройте адрес, указанный Streamlit, обычно `http://localhost:8501`.
При запуске через WSL2, если localhost недоступен из Windows, используйте Network URL, который Streamlit выводит в терминале.

## Запуск тестов

Все автоматические тесты:

```bash
python -m unittest discover -v
```

## Принятые проектные решения

- Каждое дело хранится в отдельном JSON-файле в папке data/tasks/. Повреждение одной записи не препятствует загрузке остальных.
- У каждого дела собственный черновик в data/drafts/.
- Фильтрация по дате выполняется по дедлайну дела.
